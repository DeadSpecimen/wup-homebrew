# The firmware's kernel

The stock GamePad firmware (LVC rev 7677) runs on a µITRON 4.0 kernel. Its service calls are in the firmware as small
ARM entries that load the address of the routine and a word `0xFFFFccnn` (cc: the standard µITRON function code as
a negative byte, nn: the number of arguments) and jump to a common gate at 0x91E8C. That word names every call.
Found by scanning for it; the names are the µITRON 4.0 specification's for those codes (not all are confirmed by
use: the ones libwup calls are, see `src/kernel.c`). Routines are Thumb (call the address + 1); the entries
are ARM.

State: 0xC7A88. +0x30 non-zero inside an interrupt or with dispatching off, +0x34 the running task's control block,
+0x38 -> highest priority number, +0x50 -> task table, +0x54 -> semaphore table, +0x58 -> event flag table. A table:
u16 highest id, u16 in use, then the control blocks at +4 * id. This firmware: 65 tasks (51 in use), 52 semaphores
(48 in use). Error codes are the standard ones (-18 E_ID, -42 E_NOEXS, -34 E_NOID, -50 E_TMOUT, -25 E_CTX, -17 E_PAR).
